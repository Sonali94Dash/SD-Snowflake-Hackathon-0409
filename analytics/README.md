# The Invisible Workforce Signal
**Analytics Prompt 01 | Built by Sonali & Mekala**

Streamlit dashboard that calculates attrition risk scores and classifies employees into High/Medium/Low tiers.

## Innovations
- Flight Risk Pattern Detection (Quiet Quitting, Poach Risk, Lost in Crowd, Stagnating)
- Team Size Risk Multiplier (large teams = less attention = higher risk)
- Promotion Urgency Index (months_since_promotion / tenure)
- Manager Hotspot panel (which managers need HR support)
- AI-generated retention check-in plans via Cortex COMPLETE
